# Tom's cooking agent

This pattern generates a dinner plan based on Tom's cooking preferences, equipment and schedule

   

# Example run in MacOS/Linux:

Copy the text to the clipboard and execute the following command:

``` bash
echo "4.4# sirloin tip roast" | fabric --pattern cooking_agent
```

or
    
``` bash
echo "4.4# sirloin tip roast" | cooking_agent
```
